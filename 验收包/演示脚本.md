# 任务 C 操作演示脚本

演示约 10 分钟，展示一条历史漏洞从结构化富化到引用问答，再展示两份资料的限定分析与候选审核。历史漏洞与实时监测分别介绍；现场不把候选 PoC 说成验证成功，不把测试通过率说成问答准确率。

## 演示前准备

按 [部署与联调](部署与联调.md) 启动本机系统，运行 `python -m questions.acceptance_snapshot`，确认两个主题关系为 ready。预先检查 `CVE-2024-37032`、`CVE-2025-0312` 的证据和 HF/NIST/论文资料；缺资料时在演示前补齐。联网模型可用性在准备时检查，避免在录像中展示配置或密钥。

浏览器打开 `http://127.0.0.1:8023`。录制前关闭无关窗口与个人账号信息，使用示例组件展示资产匹配。演示结束不保存虚构资产为真实清单。

## 系统现状与漏洞富化

用约 2 分钟打开「总览」「情报监测」「情报富化」，选择 `CVE-2024-37032`。展示来源、CVSS 提供者/类型/向量、版本排除上界、补丁记录及候选 PoC。展开至少一条原文引用，指出获取时间与定位。

讲解示例：这里演示一条已存档的 Ollama 历史漏洞。系统保留来源评分和版本边界，研究建议与补丁记录分别引用。当前 PoC 未由本项目运行，补丁效果也未测试；不能仅凭版本范围上界认定厂商修复版本。

若演示在线采集，明确点出实际抓取时间与失败状态，等待完成后再继续；不要在录像中剪接成实时发现一条历史漏洞。

## 有引用的多轮问答

用约 2 分钟进入「情报问答」，选择/输入编号，依次提问：

1. `CVE-2024-37032 的 CVSS 评分、来源和向量是什么？`
2. `它的受影响版本范围是什么？`
3. `那应该怎么修复？有没有修复记录？`
4. `公开 PoC 已经被本项目验证了吗？`

每轮展示片段引用和模型采用/回退提示。比较两条漏洞时明确输入两个编号，避免把不同漏洞评分拼接。点击「开始新会话」后仅问 `它的版本范围是什么？`，应提示提供编号，验证上下文已清除。

回答若回退摘录，讲解来源核对机制：当前模型输出未采用，程序保留有证据的摘录。不能把回退回答称为本轮模型正确作答。

## 跨资料的限定分析

用约 3 分钟进入「安全资料库」，确保类型为全部，使用两个示例：

| 操作 | 查看重点 | 能说明什么 |
| --- | --- | --- |
| 「填入关系示例」→「按证据回答」 | 间接提示注入机制、防护局限、NIST 红队建议与引用关系 | 不可信内容被检索和读入的概念路径；两篇文档不自动等于两次独立攻击复现 |
| 「填入供应链示例」→「按证据回答」 | Pickle 加载风险、签名边界、扫描局限及 NIST 治理建议 | 具体加载风险与一般组件治理的对照；扫描或签名不能自动变成安全保证 |

展开来源事实与限定条件，再在原文区查看物理页码/字符定位。说明模型在这条路径只选择已有分析规则，中文事实和结论按核对来源组织；目前只覆盖两个主题，不宣称支持任意新文章的多跳推理。

补充展示标准/政策资料的范围：国标记录只有官方目录，NIST 是风险框架；政策摘录应保留适用范围和施行日期，不把这些资料合并成统一的强制规范。

## 候选审核与版本失效

用约 2 分钟打开「关系候选审核」，选择模型供应链并刷新。展开一条待审核候选，查看存档上下文、分类及引用，再展示一条已通过项的审核者、审核类型、说明与时间。

同一段也可改用新文章案例：在资料列表勾选一份研究文章，主题选「所选文章」，生成候选；展开主语、原文关系、宾语、条件和整句引用。展示已核对项时注明开发来源复核身份，再点击「查看已复核关系」。空条件表示未单独提取到，不意味着无条件；摘要范围与全文分开。案例及本机记录见 [新文章关系提取说明](../新文章关系提取说明.md)。

现场生成候选会调用已配置模型，或回退句子规则。新项先待审核；重复提取不重置已有决定。只有核对原文、分类与主题后才通过；不确定时保持待审核或拒绝。已通过摘录单独展示，不能自动成为因果分析前提。

若要演示来源失效，使用合成测试结果解释，避免修改真实原文数据库。正式来源更新后，程序会关闭旧绑定或旧审核，复核记录继续保留。

## 现场故障处理

| 现象 | 操作与解释 |
| --- | --- |
| 模型超时或输出未通过 | 展示回退与证据，说明本轮未采用模型；不临时更换接口或泄露配置 |
| 来源限流或访问失败 | 展示失败状态与旧存档日期；成功缓存不称为最新抓取 |
| 关系 partial/empty | 停止该主题结论展示，核对版本/片段是否变化；可展示原文摘录，不手改数据库强行通过 |
| 检索使用 BM25 | 说明向量索引未就绪/需重建；准备阶段重建，现场不下载大模型 |
| 资产清单为空 | 使用「填入演示清单」和预览；明确其为虚构组件及版本匹配，不称为互联网资产发现 |

录像前按同一脚本演练三次，记录是否完成、失败位置和模型采用/回退情况。三次尚未完成前，不在正式材料中声称演示稳定性已验收。

# 全系统初赛验收包

当前 main 已实现多源监测、基础富化与证据归档、持久调查任务、资产风险与处置、检索和引用问答。新情报或登记资产变更触发相关研判，工具结果改变后续证据缺口；默认规则规划，可选受约束 LLM 选择。实现不等于质量或持续运行已验收。

本包按全系统初赛收尾，正式状态和步骤使用下列入口。旧“第几步”的题单、测试数、数据量和开发复核保留为带日期的历史记录，不累加为当前成绩，也不覆盖新版本。

| 入口 | 用途 |
|---|---|
| [初赛验收与交付](../docs/初赛验收与交付.md) | 必交材料、三类证据、性能测量与当前收尾清单 |
| [部署与联调](部署与联调.md) | 当前 main、隔离演示、原生/容器正式模式、索引和验收命令 |
| [演示脚本](演示脚本.md) | 全系统监测→调查→证据→风险→问答演示与失败分支 |
| [赛题要求对照](赛题要求对照.md) | 功能、阈值和仍需实际验证的边界 |
| [智能体编排与工具轨迹](../docs/智能体编排与工具轨迹.md) | 当前工具范围、模型开关、状态/租约/修订与API |
| [系统链路快照](../scripts/acceptance_snapshot.py) | 不主动排任务；可选一次真实问答，输出同CVE绑定与waiting项 |
| [任务C历史快照](../questions/acceptance_snapshot.py) | 既有固定主题和引用绑定，不能代表新系统全部功能 |
| [问答独立计分](../docs/问答独立评测与计分.md) | 冻结题单、实际答卷、人工语义核对与计分 |

技术报告 Word/PDF、初赛讲解 PPT 的 PDF、正式操作视频仍需制作；Markdown 说明不替代提交材料。真实模型/索引、资产数据质量、PoC可用性、持续时效、完整人工准确率分别验收，不将离线工程测试冒充这些结果。

Windows真实快照导入及CVE/资料两路持久消费已有 [本机交付证据](../docs/evidence/windows-actions-delivery-20261014.json)，其中 `processing_verified=false`；当前后台富化、索引和新研判结果仍应按新报告核对。

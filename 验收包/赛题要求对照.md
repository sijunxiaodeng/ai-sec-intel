# 赛题九要求与实现对照

当前 main 已具备多源监测、富化、证据知识库、混合检索和带引用问答；保留固定主题分析与可选通用有界推理，新增持久调查和资产风险处置。当前收尾入口为 [初赛验收与交付](../docs/初赛验收与交付.md)。历史整改报告保留原日期；质量指标需按当前冻结版本测量，不能根据单元测试或模型返回格式判定比赛达标。

依据为赛题九 PDF 第 1 页核心能力、第 2 页评价指标及初赛要求、第 3 页初赛阈值和决赛要求、第 4 页决赛阈值。三人计划第 5 节将 C 的范围定为富化、知识库、Embedding、BM25/向量检索、RAG 和证据问答；计划中的 GitHub PoC、Chroma 等技术设想不视作已经实现。

## 初赛与决赛指标

| 指标 | 初赛原文 | 决赛原文 | 当前证据与待验收项 |
| --- | --- | --- | --- |
| 来源覆盖 | 合格至少 3 类，良好 5 类以上，优秀 7 类以上且含实时监测 | 多源自动采集合格；广泛覆盖及增量监测良好；全自动、实时、去重优秀 | 可展示类型与订阅；类别口径及持续运行应记录，不由 URL 数量换算得分 |
| 富化维度 | 合格至少 3 种，良好 5 种以上；优秀要求准确且含自动关联推理 | 基本维度合格；多维自动富化良好；精准富化和智能关联优秀 | 多维字段可展示；PoC 可用性与互联网资产定位缺口应单列 |
| 监测延迟 | 合格 ≤24 小时，良好 ≤12 小时，优秀 ≤6 小时 | 同三档延迟，兼顾稳定性 | 按当前冻结观察窗口实测；2026-10-09旧快照的0样本不代表当前库。需记录首次发布、首次采集、未知时间、故障和补采；历史演示数据排除 |
| 富化质量 | 准确率 ≥70% / ≥85% / ≥95% | 合格准确率 ≥80% 且召回率 ≥70%；良好两者 ≥90%；优秀两者 ≥95% | 尚无独立标签与分母。不能用字段格式校验或有引用比例替代准确率/召回率 |
| 问答质量 | 基础准确率 ≥70% 合格；含推理链的深度问答良好；多跳准确率 ≥85% 优秀 | 准确率 ≥75% 且响应 ≤5 秒合格；≥90% 且支持多跳良好；≥95% 且推理链可解释优秀 | 已有开发题单和本机 HTTP 耗时；待独立问题、人工语义核对、完整引用及条件核对。原文未指定平均/P95 口径，报告须列逐题数据 |

阈值的机器可读版本见 [评分指标配置](../questions/acceptance_criteria.json)。各项得分仍由评委综合判断，不能由快照程序自动分配。

## 当前验收结论

当前是可演示的开发版本。下段本机快照及旧测试数量为 2026-10-09 历史记录；本轮回归以 [系统整改与回归](系统整改与回归.md) 为准。原主题规则题、真实 DeepSeek 题和已审核引用是开发验证；新版本独立准确率、召回率和通用多跳质量仍待核对。

快照显示本机存有 29 条漏洞记录、17 份资料和 589 个片段；两个主题的关系可用。数量包含历史资料，不能用来证明最新情报覆盖度。详情及运行时间见 [本机快照](../questions/results/task_c_acceptance_20261009.json)，后续按 [开发与验收计划](后续开发与验收.md) 补齐。

单次模型配置运行中，漏洞问答最终轮 P50 为 0.5742 秒、P95 为 1.2494 秒；资料摘录为 1.2683/2.3136 秒；固定关系分析为 0.3103/0.6923 秒。P95 使用最近秩法，小样本时等于最大值。这是复用本机进程的串行 HTTP 测量，未控制索引冷热状态、未做负载测试；历史轮次另行记录。不能把这一批低于 5 秒的请求直接写成比赛性能已经验收。

## 如何进行独立来源核对

不需要你事先知道答案。核对包逐题列出了问题、参考要点、来源链接、实际回答、引用原文及提示。可由未参与这些待测功能/规则和题单编写、也未在运行前看过题单的队友或老师复核。参与者的角色要如实记录；参与开发的复核使用 `developer_source_review`，不计独立指标。

打开本机模型运行目录的 `来源与答案核对.md`，再填写同目录 `manual_review.json`。开发复核意见另存 `developer_source_review.json`，不会自动填进人工表。

每题核对相关性、关键结论、否定/情态词与条件、引用支持及综合边界。实际核对后再把 `decision` 改为 `reviewed`，填写姓名/标识与复核类型，以及是否参与开发、运行前是否见过问题、是否已核对参考标签。未知项保持 `null`；没有综合的摘录或安全拒答，按是否保留范围核对 `synthesis_correct`，不能因没有自由生成结论就跳过其余项目。

富化题另外核对每个 `prediction_id`：正确且覆盖某个标签时填写 `supported: true` 与对应 `gold_fact_id`，错误事实填写 `false` 并解释。`gold_fact_ids` 是冻结的分母，不能删除困难标签来提高召回率。同一标签不能重复计入 TP。若参考标签本身有误，应更正题单、建立新一轮，而不是改本轮分母。

工具绑定结果内容摘要、运行编号和题单摘要；答案变动后不能沿用旧复核。完成全部对应题目的独立核对之前，独立质量指标不计算。计算范围为：

- 富化事实精确率 = TP / (TP + FP)，召回率 = TP / (TP + FN)；只覆盖本题单声明的四类维度。它不是未经确认口径的全系统“准确率”。
- 问答整题通过需五项核对均通过，接口错误仍留在分母；按新问题和已知主题边界分别统计。
- 独立复核身份和标签核对缺失、来源变化或复核未完成时，质量指标保持空值。工具始终不自动判定比赛达标。

## 运行与复现

系统启动后，在仓库根目录运行。模型模式会使用当前已配置 API；原文/规则模式不调用模型。

```powershell
python -m questions.acceptance_round --mode rules
python -m questions.acceptance_round --mode model
```

默认创建独立的本机结果目录，内含 `results.json`、`manual_review.json`、`summary.json`、`来源与答案核对.md`、`dataset.json`、`archive_manifest.json` 和 `sources/`。非空输出目录不会覆盖。只归档题单选中的原始来源及证据元数据，不复制数据库或配置。每份原始快照和元数据均记录摘要，核对包提供本地链接。原始结果及复核记录放在忽略的 `data/`，提交仓库前只导出审查过的脱敏统计。

本轮模型与规则运行各归档 10 份来源，原始字节共 1,968,700。存档是在运行后补充，并重新确认当前来源与运行记录的冻结清单相同，时点如实记为 `verified_after_capture`，没有重新调用模型或替换答案。以后命令运行会先归档来源，再捕获答案。运行前后检查失败时保留现场，不认定来源稳定。`.snapshot` 是用于核对的原始数据，可包含 HTML 或 PDF 字节；HTML 内容不作为程序执行。

填写本轮人工记录后，仅重新汇总，不再次调用模型：

```powershell
python -m questions.acceptance_round --summarize data/acceptance-round1/20261009-model
```

本轮题单固定的是这台机器的已存档证据。另一台电脑重新抓取或来源更新时可能摘要不一致；这时前置检查应失败，不能绕过。应核对新快照及参考要点、另存新题单和代码/来源清单，再运行新一轮。既有历史答案不能冒充新环境结果。

```powershell
python -m unittest questions.test_acceptance_round -v
python -m unittest discover -s questions -p "test_*.py" -q
```
